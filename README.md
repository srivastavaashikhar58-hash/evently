# Evently — India's Event Discovery Guide

Evently is a responsive web application for discovering upcoming cultural, musical, sports, and culinary experiences across major Indian cities (Bengaluru, Delhi NCR, Goa, Jaipur, Kolkata, Mumbai).

## Features

- **Search & City Filter**: Instant filtering by query keywords and city.
- **Category Filter**: Filter events by Music, Arts & Culture, Food & Drink, Sports, and Workshops.
- **Responsive & Accessible Design**: Semantic HTML5, ARIA live regions, custom CSS design system, and mobile-friendly layout.
- **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript.

## Project Structure
